[04] Selected work

Things I've built in production.

Since 2019 my work has lived in private, client-owned codebases, so there are no screenshots or repos here. I'm happy to walk through any of it in a conversation.

Unimaze Software · SaaS e-invoicing

AI-powered invoice reader

Users upload an invoice and AI fills in the fields. The hard part was the workflow around it: automation people can still check and correct.

  • Built the invoice upload flow and the view of the data AI recognized.
  • Let users review and manually correct any field before the invoice moves on to processing.
  • Designed one clear flow that combines automatic extraction with manual checks for when recognition isn't accurate.
  • React
  • TypeScript
  • AI feature UI

Freelance · iGaming back office

Real-time admin panel

Back-office and operational tools where data changes constantly and nobody should have to hit refresh.

  • Tables, filters, forms and management features across several admin modules.
  • Live updates over WebSockets for data that has to stay current in real time.
  • Tuned rendering, state handling and responsiveness for data-heavy views with frequent updates.
  • Extended the shared component system with reusable components and common patterns, so modules stay consistent and easier to maintain.
  • React
  • TypeScript
  • WebSocket
  • RTK Query

Unimaze Software · Frontend architecture

Redux to RTK Query migration

Make API communication and server data simpler and more consistent, without rewriting a running product.

  • Moved existing Redux flows to RTK Query step by step instead of in one big rewrite.
  • Cut boilerplate and simplified data fetching and caching in the migrated parts.
  • Modernized how the frontend talks to the APIs.
  • Redux
  • RTK Query
  • REST APIs

Unimaze Software · Documents & email

Invoice rendering and email templates

Generate invoices and emails from application data instead of hand-building every format as its own frontend feature.

  • XSLT stylesheets that render invoices dynamically and produce structured documents from invoice data.
  • An email template system on Microsoft Adaptive Cards for dynamic transactional emails.
  • XSLT
  • XML
  • Adaptive Cards
